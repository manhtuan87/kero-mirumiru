# ケロちゃん みるみる

ケロはかせと いっしょに、まいにち すこしずつ 「め」の たいそうを する ゲームです（5〜6歳向け。おとなも遊べます）。
任天堂の「見る力を実践で鍛える DS眼力トレーニング」のしくみ（毎日の眼年齢チェック・5つの眼力の基礎トレーニング・スポーツ・
眼のストレッチ・記録に挑戦・眼の豆知識・ハンコでメニューが増える）を、ケロちゃん シリーズのキャラクター・雰囲気で、
小さな子ども向けに作り直しました。ブラウザで動き、ケロちゃん ランド（メニュー）から遊べます（PWA、オフラインでも遊べます）。
設計は `DESIGN.md` にあります。

- **きょうの めチェック**：5つの め の ちから（うごきを みる・いっしゅんで みる・めを うごかす・まわりを みる・みて タッチ）から
  1つずつ、5つの テストで きょうの めを どうぶつで あらわします（おとなのユーザーは「めねんれい 20〜80さい」）。1日1回きろく、2回目からは れんしゅう
- **トレーニング 17しゅるい**（かんたん・ふつう・むずかしい、おとなは「おとな」も）
  - うごきを みる：シャッフル／かぞえて びゅん
  - いっしゅんで みる：ぱっと すうじ／ぱっと まる
  - めを うごかす：トリプル C／かぞえて C
  - まわりを みる：まわりの C／うえした C
  - みて タッチ：れんぞく タッチ／ナンバー タッチ
  - スポーツ：やきゅう・ボクシング・たっきゅう・バスケット・バレー・サッカー・アメフト
- 結果は 目のいい どうぶつ7だんかい（もぐら → いぬ → ねこ → ふくろう → カメレオン → トンボ → わし）と ★（★3は ミスなしの ときだけ。はんぶん いじょう まちがえると ★1）
- **むずかしい**：そのトレーニングの「ふつう」で カメレオン いじょう、または スタンプ10こで あきます
- **きろくに ちょうせん**：スポーツを ミス3回まで どこまで つづけられるか（だんだん はやく なります）。いちばんの きろくが のこります
- **めの ストレッチ**：ケロはかせと いっしょに する 目の体操（約2分、点数なし）。医学的な根拠に あわせて、がめんから めを はなして とおくを 20びょう 見る（日本眼科医会・米国眼科学会の すすめ）、まばたき たいそう、ほしを ゆっくり めで おいかける、めを とじて やすむ
- **まめちしき**：その日 さいしょの トレーニングの まえに、目の まめちしきを 1つ（48日ぶん）。見たものは「まめちしき」から いつでも読めます
- **スタンプ**：1日1こ。5こごとに はなまる。スタンプが 1こ ふえるたびに トレーニングが 1つ ふえます（11こで ぜんぶ）
- **きろく**：めチェックと トレーニングの グラフ（グラフに のるのは その日 さいしょの 1回）、きろくに ちょうせんの いちばん
- **おみせ**：あつめた★で ミミちゃん★10・ニャーちゃん★20・ワンちゃん★30（あいぼうになって いっしょに あそびます）
- **こえ**：日本語では ケロはかせが ずんだもんの声（VOICEVOX:ずんだもん）で しゃべります。なまえ（ニックネーム）は ふきだしに 書くだけで、よみあげません
- 画像と効果音・音楽は ファイルを使わず、すべてプログラムで描画・合成しています（ファイルは ケロはかせの声だけ）

## おうちの方へ

- ケロちゃん ランド（メニュー）で決めた なまえ（ニックネーム）で、ケロはかせが よびかけます（かぞくモードで名前を付けたユーザーは、その名前）
- ことば：ケロちゃん ランドの 地球のボタンで 日本語・ベトナム語・英語を えらべます（韓国語は いったん 止めています）（`localStorage` の `kero-lang`）。
  日本語以外では、ケロはかせの セリフを スマホの 読み上げ（その ことばの 声）で しゃべります（ずんだもんの声は 日本語だけ）
- タイトル画面左上の家のボタンで、ケロちゃん ランド（https://manhtuan87.github.io/）に もどれます
- タイトル画面左上の ⚙ → 管理者パスワード（123）で、管理者メニューが開きます
  - ユーザー（かぞくモード）：4人まで。名前・こども／おとな・色を決められます。2人以上いると、起動時に「だれが あそぶ？」が出ます
  - 全トレーニング解放：スタンプを待たずに、すべてのトレーニングと「むずかしい」を遊べるようにします
  - おしまいの声かけ：1日に 3つ（または 5つ）やると「めを やすめて、つづきは また あした」と声をかけます。しない こともできます
  - このユーザーの記録をリセット
- スマホの 読み上げ（なまえ・日本語以外の ことば）は Android の「テキスト読み上げ」を使います。しゃべらないときは、
  設定 → システム → 言語と入力 → テキスト読み上げ で その ことばの 音声データを入れてください（管理者メニューに 見つかったかどうか 出ます）
- 記録は この端末の中（ブラウザ）だけに保存されます

## PC で試す

```
python tools/serve.py 8770
```

ブラウザで http://localhost:8770 を開きます。**パソコン（localhost）では、テストのじゃまに ならないよう 音も声も出ません。**
音を確かめたいときは http://localhost:8770/?sound=1 を開いてください。

## 開発メモ

- 多言語：`js/lang.js`（全ゲーム共通。日本語の文をキーに `L('日本語', {変数})` で訳を引く）と `js/lang-text.js`（このゲームの訳：[ベトナム語, 英語, 韓国語]）。
  新しい文言を足したら4言語そろえる（しゃべるだけの セリフも）。結果の文は数値で記録し（`U.res`）、表示のときに訳す
- `js/app.js` … 画面・めチェックの流れ・結果・ストレッチ・まめちしき・スタンプ・記録・おみせ・管理者・メインループ
- `js/core.js` … セーブデータ（ユーザー別）・日付・スタンプ・解放（トレーニングと「むずかしい」）・ランク・めねんれい・まめちしき・きろくに ちょうせん（Node.js のツールと共通）
- `js/data.js` … どうぶつ・5つの め の ちから・トレーニング一覧・めチェック・まめちしき48・ストレッチ・ケロはかせのセリフ
- `js/trainings.js` と `js/tr/*.js` … トレーニング1つ＝1ファイル。問題作り（`gen`）と遊ぶ部分（`start`）。`peek()` は テスト用に「いま どこを タッチすれば いいか」を返す
- `js/draw.js` … キャラクターの絵（ほかの ゲームと同じ）、`js/art.js` … ケロはかせ・どうぶつ・スタンプ・C（ランドルト環）・マーク・コップなど、`js/pics.js` … 絵63しゅ（かぞえて びゅん。あたま ぐんぐんと おなじ）
- `js/sound.js` … 効果音・BGM、`js/voice.js` … ケロはかせの声（`js/voice-clips.js` は セリフ→ファイルの一覧。自動で作るので手で直さない）
- 声の作り方：`tools/voice/lines.js` に 日本語で しゃべるセリフ（と、自然に読ませるための漢字の読み方）が全部あります。
  セリフを変えたら VOICEVOX を起動して `node tools/voice/make.js`（ffmpeg が必要）。変わったセリフだけ作り直し、使わなくなったファイルは消します
- `tools/voice-test.html?sound=1` … 音を出さずに、声の順番（なまえ→セリフ）と 全部の声のファイルが読めるかを確認
- `node tools/verify.js` … 全トレーニングの問題作りを各レベル数百回ずつ動かして確認（答え・範囲・重なり・どうぶつが全部出るか・解放・セーブの読みこみ など）
- `tools/autoplay.js` … ブラウザで全トレーニングを自動で遊ばせる確認用（コンソールで読み込む。`MIRU.tick(秒)` で進める）
- アイコンは `tools/icon.html` を `tools/make-icons.ps1`（ヘッドレス Chrome）で PNG にしています
- 更新を配信するときは `sw.js` の `VERSION` を上げてください（アプリを開いたとき・アプリに戻ったときに新しい版を探し、見つかったら
  サーバーから直接 取り直して、タイトル画面で自動的に読み込み直します）。同じサイトの他のゲームと混ざらないよう、`miru-` で始まるキャッシュだけを消します
